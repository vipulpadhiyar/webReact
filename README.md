# NexaTech Solutions - Software IT Company Website

A modern, responsive website for NexaTech Solutions, a full-service software development and IT consulting company. Built with React, TypeScript, and Vite.

## Features

- **Hero Section** — Eye-catching landing with company stats and CTAs
- **About Us** — Company story and core values
- **Services** — Six comprehensive IT service offerings
- **Portfolio** — Featured project showcase across industries
- **Team** — Leadership team profiles
- **Testimonials** — Client reviews and ratings
- **Contact** — Contact form with company details
- **Responsive Design** — Fully mobile-friendly layout
- **Smooth Scrolling** — Navigation with smooth scroll behavior

## Tech Stack

- **React 19** with TypeScript
- **Vite** for fast development and building
- **CSS** with custom properties (CSS variables)
- **ESLint** for code quality

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```
