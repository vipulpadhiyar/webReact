# AgileAI Solutions Website

AI-powered software development company website built with React 19, TypeScript, and Vite 8.

## Tech Stack

- **React 19** with TypeScript
- **Vite 8** for build tooling
- **React Router** for multi-page navigation
- **Pure CSS** with custom properties (no UI libraries)

## Pages

- **Home** — Hero with rotating slides, stats bar, partner section, services grid, case studies, industries, why us, awards, testimonials, blog, clientele, CTA, FAQ, contact form, tech stack
- **About** — Our story timeline, leadership team, certifications
- **Services** — All AI/ML services with industry coverage
- **Work** — Case studies and project portfolio
- **Contact** — Contact form with office locations

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — Start dev server
- `npm run build` — TypeScript check + production build
- `npm run lint` — ESLint
- `npm run preview` — Preview production build
